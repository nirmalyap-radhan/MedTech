# Bundles a small portable pre-built ffmpeg binary -- no system install
# needed. core/config.py registers it on PATH automatically at import

# NOTE: pinned <2.0 because fasttext-wheel (used for text language-id below)
# internally calls `np.array(probs, copy=False)`, which numpy>=2.0 turned
# into a hard ValueError instead of the old "copy if needed" behavior.
# This crashed every TTS auto-detect call with
# "Unable to avoid copy while creating an array as requested."
# All other packages in this file are fine with numpy 1.x.

# Demo UI. Pinned to the 5.x line specifically: some Gradio 6.x builds
# have a regression where the Audio component's live recording waveform
# is CPU-heavy enough to freeze the whole browser tab while recording
# (github.com/gradio-app/gradio#12827, #6483). The workaround of disabling
# that waveform (waveform_options=show_recording_waveform=False) trades
# that bug for a WORSE one (#6801): recordings show "0:00 / 0:00" and
# won't play. 5.x doesn't have the freeze regression to begin with, so no
# workaround/trade-off is needed at all -- this pin is a real fix, not a
# guess.
